# Данные и воспроизводимость

Источник сообщений: [RuSentiment](https://github.com/strawberrypie/rusentiment), лицензия CC BY-NC-SA 4.0. Учебное использование некоммерческое; производные данные сохраняют атрибуцию и условия источника. Первичная ручная тональная разметка взята из корпуса, а не сгенерирована для подгонки результатов модели.

Собственный пайплайн ДЗ 3 создал очищенную версию v2 и групповые train/val/test. ДЗ 4 токенизировало её Qwen3-0.6B. Из 4616 доступных train-записей в ДЗ 5 сделан фиксированный срез 512. Тот же тензор без перетокенизации используется здесь. Для sweep параметры ограничивают общий пул первыми 32 строками и val первыми 8. Индекс проверки утечки содержит все 4770 исходных вопросов train, включая не вошедшие в короткий пул.

Golden выбран из отдельного test ДЗ 3 до генерации ответов: 17 негативных, 17 нейтральных, 16 позитивных. Число примеров — 50; одновременно есть пересекающиеся срезы short (37) / long (13). Критические классы negative и positive заданы заранее. Отбор понятных текстов и баланс классов не позволяют выдавать результат за accuracy на естественном распределении всех сообщений. В docs/golden_review.md сохранены ID, исходные группы, эталоны и основания проверки.

Хеши исходных JSONL и тензоров, связь их ID, версии golden/behavioral/training-index и ограничения проверки утечки записаны в data/eval/provenance.json. Все 512 ID тензора входят в полный исходный train-index. Точных нормализованных совпадений и пересечений group_id с golden не найдено; это не доказывает отсутствие всех смысловых перефразов. Группы ДЗ 3 — лексические хеш-корзины, не естественные авторы/документы.

Весь каталог data версионируется корневым data.dvc. Локальный remote — ../dvc_remote; он не является общедоступным сетевым адресом. Для восстановления полного набора на другой машине нужен доступ к копии этого DVC-хранилища:

```bash
dvc remote modify local url /путь/к/переданному/dvc_remote
dvc pull
```

Для преподавателя данные оценки доступны также в submission/evaluation-data.zip: golden.jsonl, behavioral.jsonl, полный training-index.jsonl, provenance.json и таблица проверки. Архив не содержит обучающих тензоров, базовых весов или адаптеров. Его следует прикрепить отдельно к сдаче; он намеренно не добавляется в Git.

Архивы публикуются отдельно от Git-истории в [GitHub Release](https://github.com/doshik722/MLOps_dz6-7/releases/tag/hw67-submission-2026-10-27): evaluation-data.zip — данные проверки с атрибуцией RuSentiment, results.zip — сырые ответы, метрики и отчёты. Полные обучающие тензоры по-прежнему передаются через DVC-хранилище, а не этот архив.

На исходном компьютере подготовка воспроизводится командой make prepare-eval из существующих папок ДЗ 3 и 5. Генератор отказывается перезаписывать уже скопированные исходные файлы другими данными.

## Вывод

Исходные задания ДЗ 3–5 не изменены. Правила оценки, эталоны и ссылки на источники фиксируются до запуска; их нельзя менять после ответов ради успешного gate.
