Выполнить make eval: отказ в выпуске является сохранённым корректным результатом. Champion при отказе отсутствует; условия и baseline не ослабляются.

Команды выполняются из hw67-broken. Если терминал занят, не вставляйте несколько команд в незавершённую строку. make eval при отказе возвращает ненулевой код — это ожидаемо; затем запускайте следующую команду отдельно.
